# Leaon

## 识图功能

本目录已配置识图能力：把图片交给智谱 AI 视觉模型（glm-4.6v-flash）转成文字描述，供不具备原生识图能力的模型使用。

### 如何添加图片并发送

在 Codex 对话框里任选一种方式：

1. **直接粘贴**：复制（或截图）图片后，在输入框按 Ctrl+V 粘贴，然后回车发送。
2. **拖拽/附件**：把图片文件拖进输入框，或点附件按钮选择图片后发送。
3. **给路径/链接**：直接输入本地图片的完整路径或网络图片 URL 并发送。

发送后 AI 会自动调用识图脚本读取图片内容（若粘贴的图片拿不到路径，会自动读取系统剪贴板）。

- `vision.js` + `run-vision.cmd`：识图脚本与启动器
