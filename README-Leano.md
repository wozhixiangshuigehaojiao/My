# Leano · 虚拟小手机

仿 iPhone 16 操作体验的黑白 ins 风「虚拟小手机」，纯前端、断网可运行。
定位：18+ 成人向线上恋爱 / AI 角色扮演互动（未成年人勿用）。

## 功能
- 开机 → 18+ 自述确认 → 锁屏（上滑解锁）→ 两页主屏
- 仿 iOS 手势：下拉通知、右上控制中心、底部上滑回主屏、App 切换器
- 角色系统：广场添加 / 接 key 解锁 / 自建人设 / 绑定自己的 key
- 核心 App：聊天（预设回复，预留真实 AI 接口）、电话、相机、照片、时钟、计算器、设置
- 自定义图片：设置 → 自定义图片，可更换壁纸、头像、组件图与 App 图标（存本机）
- PWA：可添加到主屏幕、离线缓存

## 打开
- 电脑：双击 index.html
- 手机：把 Leano-单文件版.html 传到手机用浏览器打开；
  或部署到任意 HTTPS 静态托管后安装（见 GitHub-上传步骤.md）

## 演示解锁码
LEANO-GU（顾屿）、LEANO-JIANG（江野）

## 目录
index.html / css / js / icons / manifest.webmanifest / sw.js
Leano-单文件版.html（手机离线单文件） / tools（本地服务器、重新打包脚本）
